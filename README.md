# Portfolio Data Analyst - Rizky Priyatama Putra Sugito

Website portofolio interaktif dan responsif berbasis web untuk menampilkan profil profesional, keahlian, pengalaman kerja, serta proyek-proyek analisis data (*Data Analytics & Data Management*).

---

## 🚀 Fitur Utama

- **Hero / Home:** Perkenalan ringkas, headline, dan tombol Call-to-Action (CTA).
- **About:** Profil pribadi, riwayat pendidikan, dan daftar sertifikasi profesional.
- **Projects:** Showcase portofolio proyek analisis data lengkap dengan deskripsi, teknologi yang digunakan, serta link repositori/dashboard.
- **Skills & Experience:** Tampilan keahlian teknis (Python, SQL, Excel, Tableau, dll.) serta riwayat pengalaman kerja.
- **Contact:** Formulir pesan dan tautan media sosial / kontak langsung (LinkedIn, GitHub, Email).
- **Responsive & Interactive:** Tampilan responsif (desktop, tablet, mobile), glassmorphism navbar, mobile drawer menu, dan spotlight cursor effect.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur semantik dan ramah SEO.
- **CSS3 (Vanilla):** Tata letak modern (Flexbox & Grid), variabel CSS, glassmorphism, dan micro-animations.
- **JavaScript (Vanilla ES6+):** Logika interaktivitas, navigasi dinamis, dan kontrol menu responsif.
- **Vercel:** Konfigurasi deployment melalui `vercel.json`.

## 💻 Cara Menjalankan Proyek

1. **Secara Langsung:**
   - Masuk ke direktori `source-code/`.
   - Buka file `index.html` menggunakan browser favorit Anda (Chrome, Edge, Firefox, dll.).

2. **Menggunakan Live Server (Direkomendasikan):**
   - Buka folder proyek di editor (seperti VS Code).
   - Klik kanan pada `source-code/index.html` dan pilih **Open with Live Server**.
