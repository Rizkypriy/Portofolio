## 📌 Ringkasan Sistem Industri

Aplikasi ini merupakan implementasi sistem web berbasis **Modern Dark Tech** yang dirancang untuk kebutuhan pemantauan performa industri, portofolio analitika data, serta manajemen alur kerja bisnis. Sistem ini menggabungkan prinsip rekayasa antarmuka modern (UI/UX) dengan penyajian studi kasus berbasis data (*data-driven decision making*), meliputi optimasi rantai pasok (*supply chain*), analisis lead-time, serta monitoring kendali mutu pabrik (*quality control*).

---

## 🚀 Fitur Utama Sistem

1. **Industrial Metric KPI & Highlight Stat**:
   - Visualisasi indikator kinerja penting secara langsung (akurasi data 99.4%, 120k+ rekaman data diproses, 45+ otomatisasi laporan bisnis).
2. **Interactive Project Showcase**:
   - Katalog studi kasus analitika data industri dengan label status operasional, badge teknologi, dan metrik dampak bisnis terukur.
3. **Modal Sertifikasi & Validasi Kredensial**:
   - Fitur popup interaktif untuk verifikasi lisensi dan sertifikat profesional industri.
4. **Formulir Konsultasi Bisnis & Layanan Industri**:
   - Formulir terstruktur dengan validasi interaktif *client-side* untuk pengajuan kerja sama atau konsultasi analitika data.
5. **Modern Responsive Design & Performance**:
   - Dibangun murni menggunakan **Vanilla CSS (Flexbox & CSS Grid)**, animasi mikro dinamis, efek *glassmorphism*, dan *ambient lighting* tanpa beban dependensi eksternal yang berat.

## 💻 Panduan Menjalankan Sistem Secara Lokal

Tidak memerlukan instalasi runtime atau paket kompilasi tambahan (Zero Dependency):

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/Rizkypriy/Portofolio.git
   cd Portofolio
   ```

2. **Jalankan halaman web:**
   - Masuk ke direktori `source-code/`:
     ```bash
     cd source-code
     ```
   - Buka berkas `index.html` langsung di peramban web (*browser*) favorit Anda (Chrome, Edge, Firefox, Safari):
     - **Windows**: Klik dua kali berkas `index.html` atau jalankan via PowerShell:
       ```powershell
       start index.html
       ```
     - Atau gunakan ekstensi **Live Server** di VS Code untuk pengalaman pengembangan langsung (*hot reload*).
